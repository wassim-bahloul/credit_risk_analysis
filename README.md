# Credit Risk Analysis

This repository contains a **credit risk analysis** project implemented as a **Jupyter Notebook**.

## Project overview
The goal of this project is to explore and model credit risk—i.e., the likelihood that a borrower will default—using data analysis and (optionally) machine learning techniques.

Typical steps covered in the notebook include:
- Data loading and initial inspection
- Data cleaning and preprocessing
- Exploratory data analysis (EDA)
- Feature engineering
- Model training and evaluation (if applicable)
- Summary of findings

## Repository contents
- `*.ipynb` — the main analysis notebook(s)

## How to run
1. Clone the repository:
   ```bash
   git clone https://github.com/wassim-bahloul/credit_risk_analysis.git
   cd credit_risk_analysis
   ```
2. Create and activate a Python environment (recommended):
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # On Windows: .venv\Scripts\activate
   ```
3. Install dependencies.

   If you have a `requirements.txt` file:
   ```bash
   pip install -r requirements.txt
   ```

   Otherwise, install Jupyter:
   ```bash
   pip install notebook
   ```
4. Launch Jupyter and open the notebook:
   ```bash
   jupyter notebook
   ```

## Results
Results, charts, and model metrics (if any) are produced directly in the notebook.
